# Mobile Assets

Place the following PNG files here (sizes per Expo SDK 52 conventions):

- `icon.png` — 1024×1024, app icon
- `adaptive-icon.png` — 1024×1024, Android adaptive icon foreground
- `splash-icon.png` — 200×200, splash screen logo
- `favicon.png` — 48×48, web favicon

You can copy `../../public/logo.svg` and rasterize it, or generate new ones from the Sportsphere brand.

Until these are placed, Expo will use its default assets.
